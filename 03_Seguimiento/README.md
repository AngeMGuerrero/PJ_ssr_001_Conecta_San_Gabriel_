# Seguimiento y control | PJ-SSR-001 Conecta San Gabriel

Esta carpeta reúne la línea base de programación, las evidencias exportadas de GitHub Projects y el registro general de decisiones. Los archivos de exportación son fotografías documentales de una fecha específica; el estado actualizado de las actividades se consulta en GitHub Projects y en sus Issues.

## Documentos de referencia

| Soporte | Descripción |
| --- | --- |
| [Cronograma maestro v1.3](PJssr001_CronogramaMaestro_261028_v1.3.xlsx) | Archivo Excel de referencia, con hojas **Programación** y **Seguimiento**. La hoja Seguimiento del archivo original no sustituye el estado actual del tablero. |
| [Exportación de Seguimiento semanal — 04/11/2026](PJssr001_Exportacion_SeguimientoSemanal_20261104.csv) | CSV de 14 actividades ACT-01 a ACT-14 con estado, responsable funcional, fechas, bloqueos, corte semanal y observaciones, según la captura realizada el **4 de noviembre de 2026** (hora de Bogotá). |
| [Evidencia de Cronograma general — 04/11/2026](PJssr001_Evidencia_CronogramaGeneral_20261104.pdf) | PDF de capturas de la vista Roadmap, con la programación de octubre de 2026 a abril de 2027. |
| [Registro de decisiones](Decisiones.md) | Registro general DEC-01 y referencias al expediente ACT-13 para las decisiones de gestión pendientes de transcripción verificada. |

**Precisiones sobre las fechas:** el **04/11/2026** identifica la fecha de captura y publicación de las exportaciones; el **06/11/2026** figura como valor del campo «Corte semanal» únicamente para ACT-12 en el CSV y no debe interpretarse como fecha de corte general de las 14 actividades.
